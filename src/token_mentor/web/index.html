从任务判断，到项目真正用上。

先读懂你的项目

本地分析 README 与代码，也可以直接描述需求。从真实用途出发，判断项目需要什么能力。

为任务匹配模型

文本、向量、语音与多模态任务，分别选择。不同工作，用适合的模型完成。

让成本有据可算

结合输入输出用量，权衡能力与价格。生成可下载的推荐报告，说明选择的理由。

每个项目，独立接入

在同一账户管理多个项目，为项目签发独立 API Key。用途、权限与调用归属保持清晰。

用多少，算多少

通过支付宝购买推荐次数，成功生成报告再扣次。重试不重复收费，用量随时可查。

项目内容，由你决定

敏感项目仅提交本地任务画像。需要云端判断时主动授权，对话只保留短期压缩记忆。
