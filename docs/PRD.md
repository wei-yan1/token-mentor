# PRD：Token 军师 MVP

## 产品定位

AI 任务成本军师：从项目用途出发，帮助团队比较模型价格与能力，为不同任务阶段推荐不同模型，并用有来源的成本报告解释选择。

## 目标用户和问题

面向需要控制大模型调用成本、但缺少统一价格与模型能力对照的个人开发者和小团队。用户需要知道项目是什么、哪些步骤应使用哪一档模型、单次任务成本如何估算，以及结果依赖哪些数据。

## MVP 范围

1. 读取用户描述、README/Markdown、有限源码与配置；用户描述优先。
2. 采集阿里云、DeepSeek 等 MCP 报价；以 Tavily 等搜索工具发现新厂商/模型，保存待核验来源。
3. 根据任务类型、成本、能力、稳定性、速度的可用数据排名；生成项目级 Markdown 报告和数据库建议。
4. 以 SQLite 缓存已生成结果，提供 CLI 和带 API key 的共享 HTTP API。
5. 记录用户反馈并运行小型离线测评集；通过人工评审更新规则和权重。

## 明确不做

- 不对搜索摘要、未经核验的网页片段或过期宣传内容编造标准价格。
- 不在 MVP 中调用模型执行用户项目代码或自动修改仓库。
- 不把单条用户评分直接视为新权重，不静默改变公开推荐规则。
- 不将单机 SQLite 宣称为多节点高可用数据库。

## 使用流程

`项目目录/用途 → 项目画像 → 报价与测评快照 → 任务分解和候选模型 → 成本/能力解释 → Markdown 交付 → 反馈与评估`。

## 成功指标

- 每个进入报价表的价格都有来源 URL、币种、单位和观测时间。
- 无实测评分时不显示伪精确的速度/稳定性分数。
- 相同项目画像、权重与报价快照能够命中共享缓存；价格更新后缓存自然失效。
- 用户能从报告复核模型价格、任务成本和推荐限制。
